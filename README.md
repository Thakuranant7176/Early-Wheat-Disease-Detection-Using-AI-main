# 📖 Project Overview

Early detection of wheat diseases is essential for improving crop health and reducing agricultural losses. This project uses an Artificial Intelligence model trained with **Google Teachable Machine** and integrated into a Python backend to classify wheat leaf diseases from uploaded images.

The application provides a simple web interface where users can upload an image of a wheat leaf and receive an AI-based disease prediction.

# 🚀 How to Run

### Clone Repository

```bash
git clone https://github.com/ansh-litt/Early-Wheat-Disease-Detection-Using-AI.git
```

### Open Project

```bash
cd Early-Wheat-Disease-Detection-Using-AI
```

### Run Backend

```bash
python main.py
```

Then open the frontend in your browser.
